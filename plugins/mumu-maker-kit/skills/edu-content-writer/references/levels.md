# 학습 위계와 초등 언어 기준

출발점 기준이며, 실제 단원은 교과서·지도서와 성취기준을 우선한다.

## 1. 스캐폴딩 방식 (② 탐구 → ④ 연습으로 갈수록 걷어낸다)
| 방식 | 예 |
|---|---|
| 표현 단계 | 구체물(블록·조각 조작) → 그림(막대·수직선) → 기호(식) |
| 함께 해 보기 | 내가 보여 주기 → 같이 해 보기 → 혼자 해 보기 |
| 빈칸 줄이기 | 풀이 대부분 제시 + 빈칸 1개 → 빈칸 늘리기 → 전체 스스로 |
| 힌트 단계 | 1단계: 생각 방향 질문 → 2단계: 사용할 개념 → 3단계: 첫 줄 풀이 (정답은 주지 않음) |
| 시각 단서 | 색 구분, 화살표, 강조 → 점점 제거 |
| 예시 대조 | 맞는 예와 틀린 예를 나란히 놓고 차이 찾기 |

## 2. 확인 학습 문항 설계
- 핵심 개념마다 1문항 이상, 2~4문항으로 짧게
- 오답 보기 = 대표 오개념 (예: 분수에서 "분모가 크면 더 크다", 소수에서 "자릿수가 많으면 더 크다")
- 오답을 고르면 그 오개념을 짚는 피드백 → 보충으로 연결
- 통과 기준을 정한다(예: 3문항 중 3문항, 또는 2문항 + 다시 풀기 성공)

## 3. 실전·심화 문항 유형
- 실전: 생활 맥락(가게, 요리, 운동장), 두 단계 이상, 필요 없는 정보가 섞인 문제
- 심화: 이유 설명하기, 규칙 찾기, 조건에 맞게 문제 만들기, 반례 찾기, 여러 방법으로 풀기

## 4. 초등 언어 기준
| 학년군 | 한 문장 길이(대략) | 어휘 | 문단 |
|---|---|---|---|
| 1~2학년 | 15자 안팎, 짧은 홑문장 | 생활 낱말, 받침 쉬운 말. 그림과 소리로 보조 | 2~3문장 |
| 3~4학년 | 25자 안팎 | 교과 용어 도입(처음엔 풀어 쓰기) | 3~5문장 |
| 5~6학년 | 35자 안팎, 이어진 문장 가능 | 교과 용어 정확히, 추상어 일부 | 5문장 안팎 |

- 피할 것: 이중 부정("~하지 않는 것이 아닌"), 피동 남발, 긴 수식어, 어른 말투의 한자어(예: "산출하시오", "해당하는")
- 숫자·단위는 교과서 표기대로(예: 3 1/2, 0.5 L)
- 전자칠판·화면용 글은 더 짧게: 한 화면에 핵심 문장 1~2개
