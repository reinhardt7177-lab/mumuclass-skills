# 교육용 글·문제 쓰기 — 문맥이 이어지게

이 사용자의 불만: AI가 글을 **문장 단위로 이어 붙여서** 전체 문맥이 맞지 않고, 엉뚱한 내용으로 흘러간다. 좋은 교육용 글은 **상황 → 필요(니드) → 문제 → 학생이 해결하는 과정 → 결과**가 하나의 흐름으로 이어져야 한다.

## 절차

### 1. 설계표 먼저 (글을 쓰기 전에)
아래를 표로 정하고, 큰 작업이면 사용자에게 보여 준다.
| 항목 | 내용 |
|---|---|
| 학년·단원·차시 | 교과서·지도서 기준. 성취기준 한 줄 |
| 배울 개념 하나 | 이 글·문제가 끝나면 학생이 알게 되는 것 |
| 주인공과 상황 | 누가, 어디서, 무엇을 하다가 |
| 필요(니드) | 왜 이 개념이 **꼭 필요해지는가**. 개념 없이는 해결이 안 되는 이유 |
| 문제 | 필요에서 자연스럽게 나오는 질문 |
| 해결 과정 | 학생이 밟을 단계 2~4개. 각 단계에서 쓰는 개념 |
| 결과·의미 | 해결하면 상황이 어떻게 바뀌는가 |
| 쓰면 안 되는 것 | 다음 학년 개념, 정답 미리 노출, 배우지 않은 용어 |

### 1-2. 학습 위계 설계 (문제를 잇는 뼈대)
문제는 낱개가 아니라 **단계가 있는 길**이다. 아래 위계를 표로 먼저 정하고, 단계마다 지원의 양이 줄어들게 한다. 자세한 기준은 `references/levels.md`.

| 단계 | 목적 | 지원(스캐폴딩) | 문제 형태 |
|---|---|---|---|
| ① 도입·동기 | 왜 배우는지 느끼기 | 이야기·상황 | 질문 1개, 정답 부담 없음 |
| ② 개념 탐구 | 개념을 직접 발견하기 | **많음**: 구체물 → 그림 → 기호, 함께 해 보기, 빈칸 채우기 | 따라 하기, 조작하기 |
| ③ 확인 학습 | 이해했는지 바로 확인 | **중간**: 힌트 버튼, 즉시 피드백 | 핵심 개념 2~4문항, 오개념을 진단하는 보기 |
| ④ 연습 | 익숙해지기 | **적음**: 힌트는 요청할 때만 | 숫자·상황을 바꾼 변형 문제 |
| ⑤ 실전·적용 | 새 상황에 쓰기 | **거의 없음** | 생활 맥락 문제, 여러 단계 문제 |
| ⑥ 심화 (선택) | 더 깊이 생각하기 | 없음 | 이유 설명하기, 규칙 찾기, 거꾸로 문제 만들기 |

- **갈림길**: ③에서 틀리면 바로 ④로 보내지 않고 **보충**(②보다 쉬운 표현이나 다른 모델로 다시 설명)으로 보낸다. ③~⑤를 잘하면 ⑥을 연다.
- 단계를 건너뛰지 않는다. ②보다 먼저 문제를 내거나, ③ 없이 ⑤로 가지 않는다.
- 한 단계 안에서도 쉬운 것에서 어려운 것 순서로 놓는다. 단계가 올라갈 때 **한 번에 하나만** 어려워지게 한다(숫자가 커지거나, 단계가 늘거나, 맥락이 바뀌거나 중 하나).
- 피드백은 맞음·틀림만 주지 않는다. 틀렸을 때는 **어디서 왜 틀렸는지** 학생 말로 짚고 다시 해 볼 기회를 준다.

### 2. 한 번에 쓰기
- 설계표의 순서대로 **처음부터 끝까지 한 흐름으로** 쓴다. 문단마다 앞 문단과 이어지는지 확인하면서 쓴다.
- 등장인물, 숫자, 단위, 장소, 시점을 글 전체에서 일관되게 유지한다. 앞에서 사과 12개였으면 끝까지 12개다.
- **초등 언어 기준**(자세히는 `references/levels.md`)
  - 학년 어휘로 쓴다. 문장은 짧게, 한 문장에 한 정보. 한자어·추상어보다 쉬운 우리말을 쓴다.
  - **교과서 용어는 정확히 쓴다.** 쉬운 말로 바꾸면 안 되는 수학·과학 용어(분모, 분자, 들이 등)는 교과서 표기 그대로 쓰고, 처음 나올 때 쉽게 풀어 준다.
  - 지시문은 한 번에 행동 하나만: "빈칸에 알맞은 수를 쓰세요."
  - 말투(존댓말·반말, 캐릭터 말투)를 앱 전체에서 하나로 맞춘다.
  - 발문은 생각을 여는 질문으로: "어느 쪽이 더 클까요? 왜 그렇게 생각했나요?"
- 정답이나 풀이를 글 안에 먼저 흘리지 않는다.

### 3. 문제 만들기
- 모든 문제는 **글의 상황과 필요에서 나온다.** 글과 상관없는 문제를 끼워 넣지 않는다.
- 문제 순서는 해결 과정의 단계 순서를 따른다(쉬운 것 → 핵심 → 적용).
- 정답을 직접 풀어서 검산한다. 계산·단위·표기(분수, 소수, 기호 위치)를 확인한다.
- 객관식 오답 보기는 **학생이 실제로 하는 오개념**에서 만든다. 아무 숫자나 넣지 않는다. 정답은 하나만.
- 같은 문제은행 안에서 상황·숫자·그림이 반복되지 않게 한다.

### 4. 통째로 다시 읽기 검수 (보여 주기 전에)
처음부터 끝까지 **학생이 된 것처럼** 한 번에 읽고 확인한다.
- [ ] 흐름: 상황 → 필요 → 문제 → 해결 → 결과가 끊기지 않는가. 중간에 엉뚱한 이야기로 새지 않는가
- [ ] 필요: 왜 이 개념을 써야 하는지 글만 읽고 납득되는가
- [ ] 일관성: 인물·숫자·단위·장소가 처음과 끝에서 같은가
- [ ] 문제와 글의 연결: 모든 문제가 글 내용으로 풀리는가. 글에 없는 정보가 필요하지 않은가
- [ ] 정답: 직접 검산했는가. 정답이 하나뿐인가
- [ ] 학년 수준: 어휘와 개념이 그 학년에 맞는가. 문장 길이가 학년 기준 안인가
- [ ] 위계: 도입 → 탐구 → 확인 → 연습 → 실전 → 심화 순서인가. 단계마다 지원이 줄어드는가. 한 번에 하나만 어려워지는가
- [ ] 갈림길: 확인 학습에서 틀린 학생이 갈 보충 경로가 있는가
- [ ] 용어: 교과서 용어와 표기가 정확한가
- [ ] 정답 노출: 글이나 그림에 답이 먼저 보이지 않는가
- [ ] 자연스러움: AI 번역투, 어색한 문장이 없는가(필요하면 `humanize-korean`)

검수에서 걸린 곳은 그 문장만 고치지 말고, **그 문단이 앞뒤와 맞는지 다시 확인**한다.

## 금지
- 문장이나 문항을 하나씩 생성해 이어 붙이기
- 필요(니드) 없이 "○○를 구해 보세요"로 시작하는 맥락 없는 문제
- 앞 내용과 모순되는 숫자·설정
- 검산하지 않은 정답
