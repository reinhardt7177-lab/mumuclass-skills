# 게임 선택지 사전

## 장르·핵심 루프
- 러너, 플랫포머, 탑다운 액션, 뱀서라이크(자동 공격 생존), 로그라이트
- 타워디펜스, RTS·진영전, 턴제 전술(SRPG), 카드·덱빌딩
- 퍼즐(매치3, 물리, 낙하형), 리듬, 레이싱, 슈팅(종·횡·탄막)
- 시뮬·타이쿤, 수집·육성, 방탈출·어드벤처, 파티·대전(전자칠판 다인용)
- 교육 연결 방식: 문제가 곧 조작인가 / 문제가 보상을 여는가 / 이론 뒤 적용 게임인가

## 시점·표현
- 2D 사이드뷰, 탑다운, 아이소메트릭, 2.5D(3D 배경 + 2D 캐릭터), 풀 3D(3인칭·1인칭)
- 그림체: 16비트 픽셀, HD 픽셀, 카툰, 셀 셰이딩, 로우폴리, 클레이, 페이퍼컷, 실사풍

## 손맛 목록 (기획 단계에서 정한다)
히트스톱, 화면 흔들림, 넉백, 피격 점멸, 스쿼시·스트레치, 파티클, 데미지 숫자, 콤보 카운터, 효과음 레이어, 진동, 슬로모션 피니시, 카메라 줌·추적, 레벨업 연출

## 엔진·기술 (앱에 맞게 고른다)
| 선택지 | 맞는 경우 |
|---|---|
| Phaser | 웹 2D, 빠른 배포, 전자칠판·태블릿 |
| PixiJS | 웹 2D 연출·파티클 위주, 게임 로직은 직접 |
| Three.js / R3F | 웹 3D, 사이트와 통합 |
| Babylon.js / PlayCanvas | 웹 3D 게임 기능이 더 필요할 때 |
| Godot | 2D·3D 모두 가볍게, 웹 내보내기 |
| Unity | 본격 3D·물리·애니메이션, 에셋 생태계 (라이선스·웹 빌드 크기 확인) |
| Unreal | 고품질 3D (웹 배포 어려움) |
| 순수 Canvas·DOM | 아주 단순한 교구형 |

## 쉬운 길 경고
- 사각형 맵, 원·네모로 된 캐릭터, 효과음 없는 판정
- 난이도 곡선 없이 같은 문제 반복
- 정답이 화면에 먼저 보이는 구조
