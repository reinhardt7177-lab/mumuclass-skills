# 모션·디자인 선택지 사전

방향을 제시할 때 여기서 조합한다. 이 목록이 전부는 아니며, 최신 조사에서 나온 새 기법을 우선한다.

## A. 모션 종류
| 분류 | 종류 |
|---|---|
| UI | 마이크로 인터랙션(버튼·토글·좋아요), 화면·페이지 전환, 공유 요소 전환(카드 → 상세), 로딩·스켈레톤, 온보딩, 알림·토스트, 드래그·제스처 반응 |
| 스크롤 | 스크롤 스토리텔링(스크롤리텔링), 고정(pin) 후 장면 전환, 패럴랙스, 스크롤 연동 3D 카메라, 가로 스크롤 갤러리 |
| 글자 | 키네틱 타이포, 글자 단위 리빌, 텍스트 모핑, 가변 폰트 굵기·폭 애니메이션, 타자기·스크램블 |
| 브랜드 | 로고 리빌, 인트로·오프닝 타이틀, 아이덴트, 엔드 카드 |
| 설명 | 인포그래픽·데이터 애니메이션, 익스플레이너, 다이어그램 빌드업, 지도 경로 |
| 캐릭터 | 2D 리그(뼈대), 프레임 바이 프레임, 스프라이트 시트, 립싱크, 3D 캐릭터 |
| 3D | 카메라 플라이스루, 제품 턴테이블, 3D 타이포, 오브젝트 조립·분해 |
| 효과 | 파티클, 연기·불·물 VFX, 리퀴드·블롭 모핑, 글리치, 노이즈·그레인, 빛줄기·블룸 |
| 게임 손맛 | 히트스톱, 화면 흔들림, 넉백, 스쿼시·스트레치, 데미지 숫자, 레벨업 연출, 콤보 피드백 |
| 생성형 | 절차적·노이즈 기반 패턴, 셰이더 아트, 사운드 반응 비주얼 |

## B. 제작 방법·도구
| 방법 | 잘하는 것 | 주의 |
|---|---|---|
| CSS transition·keyframes | 단순 UI 상태 변화 | 복잡한 연출엔 한계, 기본값 남발 주의 |
| CSS 스크롤 기반 애니메이션(animation-timeline) | 가벼운 스크롤 연동 | 브라우저 지원 확인 |
| View Transitions API | 페이지·요소 전환 | 브라우저 지원 확인 |
| Web Animations API | JS 제어가 필요한 가벼운 모션 | |
| GSAP (+ScrollTrigger, SplitText, Flip, MorphSVG) | 정밀한 타임라인, 스크롤 연출, 글자 분해 | 공식 문서 확인 |
| Motion (구 Framer Motion) | React 컴포넌트 전환, 스프링, 레이아웃 애니메이션 | React 전용 |
| Rive | 상태 머신 기반 인터랙티브 캐릭터·아이콘, 아주 가벼움 | 에디터 작업 필요 |
| Lottie / dotLottie | After Effects 작업을 웹·앱에서 재생 | 상호작용은 제한적 |
| Spline | 웹용 3D 장면·인터랙션을 빠르게 | 무거울 수 있음 |
| Three.js / R3F + 셰이더(GLSL) | 3D, 파티클, 왜곡·리퀴드 효과 | 성능 관리 필요 |
| PixiJS / Canvas 2D | 2D 대량 스프라이트·파티클 | |
| Phaser tweens·particles | 2D 게임 연출 | 공식 문서 확인 |
| Unity Animator·Timeline / Godot AnimationPlayer | 엔진 게임 연출 | |
| Theatre.js | 웹 3D·DOM을 타임라인 에디터로 연출 | |
| Remotion | React로 영상 렌더링(mp4) | 실시간 앱용 아님 |
| skia-python + 비트 그리드 | 타이포 전용 릴스 영상 | 타이포 영상 제작용 |
| After Effects / Blender | 고품질 렌더 영상·3D | 사용자 작업 또는 결과물 활용 |
| AI 영상(Kling, Seedance 등, Higgsfield) | 실사·시네마틱 장면 | 정밀 제어 어려움, 크레딧 확인 |

## C. 풍(스타일)
- **그래픽**: 스위스·그리드 타이포, 네오 브루탈리즘, 미니멀 애플풍, 에디토리얼 매거진, Y2K·크롬, 레트로 70~80s
- **질감**: 그레이니 그라디언트, 리소·인쇄 질감, 종이·페이퍼컷, 콜라주·스톱모션, 손그림·러프 스케치
- **입체**: 클레이 3D, 글래스모피즘, 아이소메트릭, 로우폴리, 시네마틱 3D
- **게임·애니**: 16비트 픽셀 FX, 셀 애니메이션 FX(애니 이펙트), 카툰 러버호스, 아케이드 네온
- **유체**: 리퀴드·블롭, 메타볼, 잉크 번짐

## D. 타이밍 기준 (출발점, 고정값 아님)
- UI 반응 100~200ms, 화면 전환 250~500ms, 연출 장면은 비트 단위
- 들어올 때는 감속(ease-out 계열), 나갈 때는 가속(ease-in 계열), 튀는 느낌은 스프링·오버슈트
- 여러 요소는 스태거 30~80ms로 순서를 준다
