# 이미지·3D 에셋 선택지 사전

## 원칙
- 그림은 이미지 에셋으로 만든다. 코드·SVG·CSS 도형·이모지로 대신하지 않는다.
- 레퍼런스로 받은 이미지는 앱에 직접 쓰지 않는다.
- 한 시트에 4개 이하, 번호 없이, 투명 배경, 비율 고정.
- 같은 앱의 에셋은 화풍·빛 방향·외곽선 굵기·채도를 통일한다(스타일 가이드 한 장 먼저).

## 만드는 방법
| 방법 | 맞는 경우 |
|---|---|
| 이미지 생성(나노바나나, GPT 이미지, 힉스필드 등) | 캐릭터·배경·아이템·썸네일 |
| 이미지 생성 → 누끼 → 업스케일 | 게임 스프라이트, UI 일러스트 |
| 스프라이트 시트·프레임 애니메이션 | 2D 캐릭터 동작 |
| Meshy 등 3D 생성 → Blender 정리 | 3D 소품·캐릭터 |
| Blender 직접 모델링·렌더 | 일관된 3D 세트, 오프닝 |
| 사진 실사 | 1~2학년 교구, 과학 자료 |
| 벡터 일러스트(사람이 그린 것) | 아이콘 세트, 로고 |

## 확인
- 해상도: 표시 크기의 2배 이상(레티나)
- 같은 화면 안에서 크기·원근·바닥 접지(그림자) 맞추기
- 파일 용량과 포맷(webp·avif·png) 최적화
